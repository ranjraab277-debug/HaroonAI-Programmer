# Haroon AI Programmer V1

Real AI coding chat using the OpenAI Responses API through a Node/Express backend.

## Render
Build Command: npm install
Start Command: npm start
Environment Variables:
OPENAI_API_KEY = your NEW secret key
OPENAI_MODEL = gpt-5.6-luna
PORT is supplied by Render; do not hard-code it.

Do not put the API key in the browser, Roblox LocalScript, or GitHub.
